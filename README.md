# 高性价比人生指南 · 行动版

在线阅读：https://guozhengxin.github.io/

这是读者基于开源书《高性价比人生指南》改编的「行动版」网页，不是作者官方版本。

## 和原书的关系

- 原文出处：[eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)（作者：永恒世界）

- 代码许可：MIT（原仓库 index.html 属于代码范围）
- 本站同步的正文版本：2026-10-31 版，未改动正文内容

## 本站改了什么

- 保留原书的搜索、成本/时间/毅力筛选与章节结构
- 新增「待做 / 已做到 / 暂不适合」标记、行动格子、进度导出/导入
- 删掉了与公开阅读无关的本地入口和个人内容
- 页脚补充出处、许可和改动说明

## 维护方式

本地改好页面后重新构建并推送本仓库，GitHub Pages 会自动更新（约 1 分钟生效）。
本站不放统计脚本；读者的标记和进度只存在各自浏览器里，不上传。
